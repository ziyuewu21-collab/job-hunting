# 求职一条龙

一个手机也能用的求职工作台：认识我 → 岗位分析 → JD 拆解 → 简历定制 → 投递看板 → 面试陪练。

## 怎么打开

- 网页：仓库 Settings → Pages 开好后，地址是 `https://<你的用户名>.github.io/job-hunting/`
- iPhone：用 Safari 打开 → 分享 → 添加到主屏幕，以后就像 App 一样点开

## 数据存在哪里

- 你在页面上做的所有修改（简历、拆解过的 JD、看板状态、练习答案）都存在**这台设备的浏览器**里，不会上传
- 换设备或清缓存前，先去「概览 → 导出备份」
- `data/jobs.json` 是岗位和弹药的种子数据，Claude 会往这里加东西

## 和 Claude 配合

1. 把岗位截图、JD 或小红书面经发给 Claude
2. Claude 整理后写进 `data/jobs.json` 并推到这个仓库
3. 打开网页 →「概览」→「从仓库同步」：新岗位会并进来，你自己改过的卡片不会被覆盖

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 整个工作台（单文件，无后端） |
| `data/jobs.json` | 岗位 + 面试弹药种子数据 |
| `manifest.json`、`icon-*.png` | 添加到主屏幕用 |

## 关于"AI 分析"

简历解析、JD 关键词提取、匹配度计算、面试题生成都是本地规则（正则 + 词库匹配 + 题库模板），不联网。需要真正的判断（值不值得投、开放题怎么答），发给 Claude。
